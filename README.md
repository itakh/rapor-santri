# Rapor Santri — tampilan (GitHub Pages)

Tampilan aplikasi Rapor Santri Ma'had Tahfizhul Qur'an Tarbiyah Sunnah. Data disimpan di Google Sheet melalui Apps Script (repositori terpisah, privat).

Repositori ini **publik** dan sengaja **tidak** memuat data santri, sandi, maupun TTD/stempel; semuanya baru dikirim server setelah pengguna masuk.

- Alamat server diatur di `config.js`.
- Diperbarui dari berkas sumber dengan `build_web.py`.
